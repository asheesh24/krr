What is a Bayesian Network?

A Bayesian Network is a probabilistic graphical model that represents relationships between different variables using nodes and directed connections.


In student performance prediction, variables such as attendance, study hours, previous examination marks, assignment scores and participation can be connected to the final performance of a student.


The model uses probability to estimate the likelihood of different performance levels based on the available student information.

Factors Used in Prediction

📚 Study Hours

The number of hours a student spends studying can influence the probability of achieving good academic performance.

📅 Attendance

Regular attendance provides students with more opportunities to attend lectures and understand course concepts.

📝 Previous Marks

Previous examination results can provide useful evidence about a student's expected performance.

📖 Assignment Score

Assignment performance can indicate the student's understanding and consistency.

👨‍🏫 Participation

Classroom participation can be considered as another factor related to academic performance.

🎯 Final Performance

The Bayesian Network combines evidence from different variables to estimate the student's performance.
